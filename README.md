# Dr. Dhanita Khanna — Website

A lightweight, responsive static website for Dr. Dhanita Khanna's professional practice in Lucknow.

## Project structure

```text
 dr-dhanita-khanna-website/
 ├── index.html                 # Page structure and website content
 ├── css/
 │   └── styles.css             # Design tokens, layout, components, responsive styles
 └── assets/
     └── dr-dhanita-khanna.png  # Doctor portrait used in the homepage hero
```

## Technology

- Semantic HTML5 for content and page structure
- Plain CSS for styling and responsive layouts
- Google Fonts: DM Sans and Source Serif 4
- No JavaScript framework or build step is required for this initial version

## Run locally

Open `index.html` in a browser, or use the VS Code **Live Server** extension for a local development server.

## Deploy

This is a static site. It can be deployed directly to Vercel, Netlify, or GitHub Pages. For Vercel, import the repository and use the project root as the deployment root; no build command is required.

## Where to make changes

- Update wording, links, navigation, and page sections in `index.html`.
- Update colours, typography, spacing, component styles, and responsive rules in `css/styles.css`.
- Replace the portrait by overwriting `assets/dr-dhanita-khanna.png` with an appropriately optimized image, keeping the same filename, or update the image path in `index.html`.

## Current scope

This is the frozen first homepage version. The reviews carousel, patient-friendly condition explanations, FAQ, enquiry form, and subtle reveal animations are intentionally not included yet; they will be added in a separate, structured pass.

## Before public launch

- Verify clinic and hospital contact details and appointment links.
- Confirm clinic and Max consultation timings.
- Confirm all clinical descriptions and conditions with Dr. Khanna.
- Only publish genuine patient reviews with appropriate permission and attribution; do not fabricate or rewrite reviews in a misleading way.
- Connect the final domain and verify all links on desktop and mobile.
